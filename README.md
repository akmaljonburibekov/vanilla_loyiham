## 🎨 Dark / Light Mode

Dark va Light mode CSS variables orqali boshqariladi.

Light mode:

```css
:root {
  --main-bg: #FCF8FF;
  --white-bg-color: #ffffff;
  --main-text: #1a1a1a;
  --footer-bg-color: #E9E6F8;
}
```

Dark mode:

```css
.dark {
  --main-bg: #1a1a1a;
  --white-bg-color: #252525;
  --main-text: #ffffff;
  --footer-bg-color: #333333;
}
```
